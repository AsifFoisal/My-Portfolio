About Me

nameG.M Asif Foisal
roleFull Stack Developer
stackMERN + TypeScript
locationDhaka, Bangladesh
status● open to work

Turning curiosity into clean code — one commit at a time.

My journey started in 2019 with a simple act of rebellion: right-click → Inspect Element. I wanted to change the color of a button on my favorite website, and somehow ended up rewriting my entire career plan. A few months later I wrote my first "Hello, World!" in Python, then discovered C in my first university semester — but the real spark came when JavaScript let me make things move, react, and feel alive in the browser. I've been hopelessly hooked ever since.

Today I work across the full stack — architecting REST APIs and database schemas on one tab while fine-tuning a component's micro-interaction on the other. The work I enjoy most lives where product thinking meets engineering: taking a fuzzy idea, shaping it into something people actually love using, then obsessing over load times, accessibility, and clean architecture until it ships right.

If I had to describe myself in one line: I'm the person who reads documentation for fun, names Git branches like movie titles, and genuinely believes console.log is a valid debugging strategy — right up until it isn't.
